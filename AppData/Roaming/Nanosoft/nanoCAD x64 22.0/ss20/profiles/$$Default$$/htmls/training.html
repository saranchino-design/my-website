Обработка растра Вставка растра
  1. Создайте новый документ.

  2. Вставьте растровое изображение командой Вставка растра  одним из способов:

    • ЛЕНТА: Растр > Файл > Вставка растра

    • Функц. панель ИНСТРУМЕНТЫ: Растровый учебник > Файл > Вставка растра

      • Вызов функциональной панели Инструменты:

      ЛЕНТА: Настройки > Функциональные панели > Инструменты  

    Откроется диалог Вставка изображения:

  1. В диалоге нажмите кнопку Обзор и найдите файл Втулка.tif (C:\Users\пользователь\AppData\Roaming\Nanosoft\nanoCAD Plus 20.1\TestDrive\Raster).

  2. Включите Указать на экране точку вставки и нажмите ОК. В модельном пространстве появится рамка (граница) растра. Левой кнопкой мыши (ЛКМ) кликните в любом месте пространства.

Коррекция цветного изображения по гистограмме
  1. Вызовите команду Уровни по шаблону  одним из способов:

    • ЛЕНТА: Растр > Обработка > Уровни по шаблону

    • Функц. панель ИНСТРУМЕНТЫ: Растровый учебник > Обработка > Уровни по шаблону

  2. Задайте пороговое значение для темных тонов: используя темную пипетку (взять пробу для низшей отметки), укажите на экране цвет, который должен стать черным (выберите один из светлых пикселей на черной части изображения).

  3. Затем задайте пороговое значение для светлых тонов: используя светлую пипетку (взять пробу для высшей отметки), укажите на экране цвет, который хотите преобразовать в белый (выберите один из темных пикселей на фоне).

  1. Нажмите кнопку Применить.
 Все пиксели, имевшие значение яркости ниже порога темного, получат нулевое значение яркости, а пиксели со значениями яркости выше самого яркого – максимальное значение яркости.

  3. Кликните по нужной части загруженного растра. Появится красная рамка с границами окна просмотра.
  1. В списке По выберите метод Серый.

  2. В списке Канал тоже выберите Серый.

  3. Подберите пороговые значения для параметра G.

  4. Нажмите на кнопку Применить.

    5. Поверх исходного цветного растра появится новый монохромный растр.

  1. В появившемся диалоговом окне выберите исходный растр и нажмите кнопку Delete на клавиатуре.

    Обведите прямоугольной рамкой текст, который нужно изменить, начиная с горизонтальной базовой линии:

  1. Введите новый текст и нажмите на Enter. Поверх исходного растрового текста появится новый векторный текст:

  1. Выберите Нет для растеризации текста.

Перевод растровой графики в векторный формат Настройка параметров конверсии для векторизации
  1. Откройте файл NC_Mech.dwg.

  1. Запустите команду Параметры  одним из способов:
    • ЛЕНТА: Растр > Преобразование > Параметры преобразования

    • Функц. панель ИНСТРУМЕНТЫ: Растровый учебник > Преобразование > Параметры преобразования

  2. На вкладке Распознавание отметьте Линии (типы линий и стрелки), Дуги и Окружности (типы линий и стрелки), Текстовая область (OCR), Штриховки (±45°).

  1. На вкладке Параметры задайте максимальную толщину, максимальный разрыв, высоту текста, размер стрелки, установите точность и настройте ортогонализацию.

  1. Для задания максимальной толщины нажмите кнопку Измерить значение   напротив поля Максимальная толщина и пересеките наиболее широкую линию чертежа. Полученное значение имеет смысл немного увеличить.

В данном примере установите максимальную толщину, равную 1.5 мм.
  1. Задайте максимальный игнорируемый разрыв в растровых линиях. Установите разрыв, равный 0.5 мм.

  2. Для задания высоты текста нажмите кнопку Измерить  значение напротив поля Высота текста и измерьте максимальную высоту текста:

  1. Для задания размера стрелки нажмите кнопку Измерить  значение напротив поля Размер стрелки и обведите стрелку прямоугольной рамкой:

  1. Точность установите в область низких значений и включите ортогонализацию.

  2. На вкладке Разделение настройте свойства создаваемых векторных объектов (ширину, слой, цвет).

  3. Для разделения интервала (от 0 до 1.5 мм) на несколько диапазонов (от 0 до 0.8 мм и от 0.8 мм до 1.5 мм) щелкните левой клавишей мыши в нужном месте линейки таблицы толщин:

  1. Включите флажок Использовать таблицу.

  2. Для первого диапазона задайте ширину – 0.25 мм, слой – 1, цвет – красный. Для второго задайте ширину – 0.5 мм, слой – 2, цвет – зеленый.

  1. На вкладке Тексты задайте горизонтальную и вертикальную ориентацию текста, включите Отдельно стоящие буквы, файл с OCR-символами задайте default.ocr.

  1. Для настройки OCR нужно задать набор шаблонов слов. Шаблон слова – это правило, задающее разрешенную последовательность символов в пределах одного распознанного слова. Модуль OCR будет распознавать только те слова, которые соответствуют одному из заданных шаблонов.

Кнопки Добавить шаблон  и Удалить шаблон  управляют составом списка шаблонов слов. Ниже приведено формальное описание определения шаблона слова:
[% [длина] тип символа] || [буква]] …
 Параметры определения шаблона слова:
ПараметрЗначение
[%]Начало определения последовательности символов
[длина]Любое десятичное число; отсутствует при переменной длине
[тип]Тип символа (D, E, e, N, n, S)
[буква]Одиночная буква
Кодировка типов символов:
Кодировка символаРасшифровка
DЦифры
EБуквы английского алфавита верхнего регистра (первый алфавит)
eБуквы английского алфавита нижнего регистра (первый алфавит)
NПрописные буквы национального алфавита, например, русского (второй алфавит)
nСтрочные буквы национального алфавита, например, русского (второй алфавит)
SСпециальные символы (знаки плюс и минус, знак равенства и т.д.)
%%Одиночный символ «%»
[буква]Одиночный символ
Например: Шаблон Rz%D соответствует словам, которые начинаются с «Rz», после чего следует любая последовательность цифр, например, «Rz40», «Rz2.5», «Rz5000». Шаблон %1N%n соответствует словам национального алфавита с прописной первой буквой, например «Ганновер», «Осло», «Москва». Шаблон %D%% соответствует словам следующего образца: «20%», «1100%», «12.50%». Шаблон %DV соответствует словам следующего образца: «5V», «220V», «13.8V». В поле Таблица высот задайте возможные высоты текстов. Если установить флажок, то при генерации распознанных текстов модуль OCR будет создавать текстовые объекты с высотами из этого списка, производя округление распознанной высоты к ближайшей из заданных в списке. Настроенные параметры конверсии можно сохранить в файле набора параметров (*.tpl), нажав кнопку Параметры:

Сохраненный файл набора параметров можно использовать для обработки растров, имеющих схожее качество.
  1. Для принятия параметров конверсии нажмите кнопку ОК.
Векторизация в режиме трассировки

  1. В файле NC_Mech.dwg трассируйте сечение А-А.

1.1. Включите режим Создание вектора и стирание растра  одним из способов:
  • ЛЕНТА: Растр > Трассировка > Создание вектора и стирание растра

  • Функц. панель ИНСТРУМЕНТЫ: Растровый учебник > Трассировка > Создание вектора и стирание растра

1.2. Запустите команду Автотрассировка  одним из способов:
  • ЛЕНТА: Растр > Трассировка > Автотрассировка
