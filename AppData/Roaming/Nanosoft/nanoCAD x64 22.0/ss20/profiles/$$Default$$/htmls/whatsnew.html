Что нового в Платформе nanoCAD 21
Перечень новых возможностей в Платформе nanoCAD 21 Подробное описание новых возможностей платформы можно посмотреть по этой ссылке. Краткий список основных новшеств платформы nanoCAD 21:
  • Режим изометрического черчения;
  • Ассоциативные массивы;
  • Подложки с картографических сервисов;
  • Новый уровень работы с внешними ссылками (плавающая панель и команды);
  • Абсолютно новый диалог для работы с полями;
  • Развитие и пополнение средств работы с группами;
  • Полностью переработанная панель «Нормааудит»;
  • Выбор объектов с помощью «лассо»;
  • Расширенная вставка из буфера по ПКМ;
  • Многократное копирование при нажатом Ctrl при переносе/повороте/масштабировании;
  • Множество улучшений режимов динамического ввода;
  • Доработка функционала таблиц и полей;
  • Доработка функционала мультивыносок;
  • Создание окружности по трём касаниям;
  • Модернизация работы с закладками листов;
  • Сохранение «несохранённых» файлов и возможность возврата к файлам автосохранения;
  • OLE-сервер для «живой» интеграции .DWG файлов во внешние редакторы;
  • Возможность работы при потере связи с сервером лицензий.
Расширение редактора блоков:
  • Поддержка конфигураций посредством управления видимостью объектов блока;
  • Возможность добавления, удаления и изменения объектов блока при сохранении параметрических зависимостей.
Разрушаем стереотипы:
  • Построение дуг (включая эллиптических) в сторону движения мыши;
  • Двусторонний список истории изоляции/скрытия объектов.
Для тех, кто прочно стоит на земле или уверенно витает в облаках:
  • Новый модуль «Топоплан»;
  • Развитие инструментов работы с облаками точек.
Подробное описание и список остальных доработок и улучшений – в онлайн-версии «Что нового».
